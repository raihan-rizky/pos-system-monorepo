# Cetak dan unduh Laporan Harian

1. Buka **Laporan Keuangan** dengan izin Lihat laporan keuangan dan Ekspor laporan.
2. Klik **Laporan Harian** di samping **Ekspor**. Jika filter halaman memilih satu hari, pratinjau memakai tanggal tersebut. Jika filter mencakup beberapa hari, pilihan awalnya adalah hari ini dalam WIB.
3. Pilih tanggal hari ini atau sebelumnya. Periksa Jurnal Transaksi, ringkasan, metode pembayaran, serta omzet per kategori dan subkategori.
4. **Banyak halaman** menjadi pilihan awal. Mode ini memuat jurnal per invoice dengan kepala tabel berulang. Pilih **1 halaman** untuk ringkasan pemasukan, pengeluaran, metode pembayaran, dan omzet per kategori serta subkategori dalam satu lembar A4 lanskap.
5. Klik **Cetak A4** untuk membuka dokumen siap cetak atau **Unduh PDF** untuk menyimpan file bernama **laporan-harian-YYYY-MM-DD.pdf**.

Pada mode **1 halaman**, daftar kategori, subkategori katalog, jenis nota percetakan, dan metode penerimaan tampil lengkap. Yang belum memiliki transaksi pada periode laporan ditampilkan sebagai **Rp 0**.

**Total Pemasukan** dan rincian metode pembayaran memakai data penerimaan yang sama dengan **Pemasukan Harian** di tampilan Sales. **Total Pengeluaran** mengikuti laporan lengkap pada tanggal WIB yang sama dan tampil sebagai pengurang pada Grand Total. Baris Jurnal Transaksi mengikuti tanggal nota atau pengeluaran. **Omzet**, **Laba Kotor**, serta omzet per kategori dan subkategori mengikuti laporan penjualan untuk tanggal tersebut.

Kedua mode tersedia juga di **Ekspor → Jurnal transaksi · Excel / PDF** saat format PDF dipilih.

Pratinjau, cetak, dan unduhan memakai data dari tanggal yang sama. Jika data gagal dimuat, klik **Coba lagi** di pratinjau. Jika browser memblokir jendela cetak, izinkan pop-up lalu klik **Cetak A4** lagi.
